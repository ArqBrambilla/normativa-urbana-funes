# Normativa urbana de Funes — prototipo

Mapa interactivo con los índices urbanísticos de la Ordenanza 288/85 de Funes (Santa Fe), basado en el relevamiento SIG de la Comuna.

Sitio estático: `index.html` + archivos de datos (`.geojson`/`.json`). No requiere servidor, build ni conexión a QGIS para funcionar — ver el instructivo de actualización de datos para el mantenimiento.

**Esto es un prototipo interno**, no reemplaza el certificado oficial de factibilidad del Concejo.
